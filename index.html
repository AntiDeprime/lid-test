Leben in Deutschland Test FAQ

How is the mock test built?
Each run uses 30 general questions and 3 Berlin Bundesland questions.
What score is needed to pass?
You need 17 correct answers out of 33, matching the Einbürgerungstest threshold.
Can I review mistakes?
Yes. The result screen shows missed questions, and the start page keeps a weak-question review set across sessions.
